On the use of AI
================

When has AI been used?
----------------------

Statement by the creator (Antonio Rocha):
    
    AI was used to help the development of this project. However, all code
    generated by AI was thoroughly reviewed and extensively rewritten.

    I have used AI to help generate documentation, which again, was personlly
    100% reviewed, and rewritten when deemed necessary. This was done to speed
    up the process of publishing the package, which was necessary for personal
    reasons (I love writing documentation).

    I have used AI to generate translations for other languages, for the same
    reason as before (speeding up the process of publishing the package). I wanted
    to release the package with more than just the 2 languages (outside English)
    I speak (in the hopes of popularizing it). I hope native speakers of these
    languages will read through the translation and contribute to it with suggestions
    and corrections.

    Personally, I believe in the use of AI as a tool. I would have lost countless
    hours trying to make python's hooks work without it. The first simple working
    implementation the AI generated gave me served as a starting point to research
    and learn how the process worked (I had no idea what hooks even were). 
    In the end, I managed to decrease the ~60 lines of code the AI had 
    generated to just ~10, while improving the feature tremendously (it is now much more
    general).

Contributions using AI
----------------------

As stated
in the :ref:`contributing section <contributing>`, the contributor must state
if and how AI was used.

Language support
~~~~~~~~~~~~~~~~ 

AI can be used to speed up translations, giving a base on which the native speaker 
contributing to the package can **review critically** and make changes. Translations
made entirely by AI by a user who does not speak the langauge will not be accepted.

Code
~~~~

As in the personal statement by the creator, AI can be used for helping develop
concepts and code. However, all code must be **thoroughly reviewed** (and if necessary rewritten)
by a human, taking into account (in particular) the security implications of said code.
